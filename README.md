Лендинг для частного мастера по химчистке мебели

Одностраничный сайт, разработанный с нуля для мастера из Тюмени. Проект сочетает в себе современный UX/UI, высокую производительность и кастомные технические решения для обработки заявок.

## 🛠 Технологический стек
* **Frontend:** HTML5 (семантика), CSS3 (Flexbox/Grid, адаптивность), JavaScript (ES6+).
* **Backend-интеграция:** Google Apps Script (обработка форм, защита от спама).
* **Хранение данных:** Google Sheets API (использование таблиц в качестве базы данных).
* **Безопасность:** GitHub Actions (CodeQL), Web Crypto API.
* **Хостинг:** GitHub Pages.

## 🚀 Ключевые особенности и реализованные задачи

### 1. Собственная система обработки заявок
Вместо использования готовых конструкторов, была разработана связка:
- **Frontend-валидация:** Проверка полей формы перед отправкой.
- **Интеграция с Google Sheets:** Все заявки мгновенно попадают в таблицу заказчика.
- **Защита данных:** Реализована через Google Apps Script, что скрывает конфиденциальные эндпоинты от публичного доступа.

### 2. Безопасность и архитектура
- **Secure ID Generation:** Использование `crypto.randomUUID()` вместо `Math.random()` для генерации идентификаторов сессий (соответствие стандартам криптографической безопасности).
- **Code Scanning:** Настроено автоматическое сканирование кода через GitHub CodeQL для выявления уязвимостей.
- **Zero Dependencies:** Проект написан на чистом (Vanilla) JS без использования тяжелых библиотек, что обеспечивает мгновенную загрузку.

### 3. UX/UI и Оптимизация
- **Mobile First:** Полная адаптивность, включая кастомное бургер-меню с интегрированными контактами.
- **SEO-оптимизация:** Использование `object-fit` для Hero-изображений вместо фоновых свойств CSS для лучшей индексации поисковиками.
- **Контентная стратегия:** Проработаны блоки доверия (рейтинги Авито), прайс-листы и FAQ.
